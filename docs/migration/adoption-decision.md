# Decision: consolidate Liminal authority into one SAS

Status: accepted by Brian through the [exact SAS acceptance](sas-acceptance-receipt.md).
OpenWarrant registration remains pending the human authority register. Phase GO
and suite ratification remain separate. This migration decision is not an
allocated ADR; no ADR number or retrospective approval is created.

## Problem

Liminal's constitutional meaning, accepted refinements, execution orders and
roadmap span many documents. OpenWarrant has no registered Liminal SAS. Current
navigation repeats historical Phase -1 status, while execution has reached the
M17 qualification gate. Several source orders make suite ratification a
prerequisite for the very work ADR-0021 requires before ratification.

## Accepted decision

Accept one digest-bound SAS revision as the sole governing specification,
preserving complete v4/R4 clauses, accepted decisions, constitutional chapters,
phase scope and unresolved gaps through explicit incorporation and precedence.
Keep every original document and its citation history. Use stable LIM-SAS-RQ
identifiers and a machine-readable source/HAQP/Warrant/evidence crosswalk.

Use one production roadmap for the complete Phase -1–12 program. Sequence the
first distributable qualified OpenWarrant compiler through M17 closeout,
M18–M24 qualification, accepted integration interfaces, pinned profile,
whole-corpus byte-and-semantic parity, and reproducible release. Draft only
near-term Warrants; author later mechanical contracts at their preceding gates.

Apply the SAS's exact reconciliations for stale source status, obsolete absolute
meter predictions and circular ratification language. Preserve relative named
gate deltas, every HAQP threshold and all T1 decision boundaries. Incorporation
does not resolve open amendments or create retrospective approvals.

## Alternatives and tradeoffs

Keeping all documents as coequal living authority perpetuates conflicts.
Replacing them with a short summary risks losing qualifications and later-phase
obligations. Lossless incorporation produces a long SAS, but exact source
anchors and the requirement index make every original obligation reviewable.
The historical source manifest is deliberately strict; campaign integration
requires an explicit reconciliation of any changed original source.

## Acceptance meaning

Acceptance establishes specification authority for the exact SAS bytes and
the stated migration reconciliations. It does not declare the SAS fulfilled,
authorize M18 implementation, close Phase 0, ratify the Phase 1 suite, resolve
any Warrant, or approve release. Those remain separately evidenced decisions.

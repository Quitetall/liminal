## Scope

one already-selected Holder and a Liminal-owned, `rowan 0.16.1` bounded,

## Pre-made decisions

- **D18.1 —** the source buffer is `ropey 1.6.1`; it is a physical UTF-8 view of
  bytes supplied by an already-resolved Holder, never a competing Holder or
  semantic authority.
- **D18.2 —** production CST storage is `rowan 0.16.1`, wrapped entirely by
  Liminal-owned types; no rowan type crosses a serialized or public interchange
  boundary.
- **D18.3 —** `MAX_SOURCE_BYTES = u32::MAX as u64`, matching rowan `TextSize`;
  `MAX_NESTING = 256`; `MAX_ERRORS = 1024`. Exceeding a bound returns a typed
  result and never panics or drops source text.
- **D18.4 —** L0 accepts well-formed UTF-8 only. Invalid UTF-8 is a Holder-load
  error with exact byte coordinates; malformed *syntax* remains valid input and
  is retained inside `ERROR` nodes.
- **D18.5 —** every input byte belongs to exactly one rowan token in source order.
  Error recovery wraps existing tokens; it never synthesizes, deletes, or rewrites
  token text. Concatenating all tokens therefore reproduces the UTF-8 input bytes.
- **D18.6 —** the supported frontend is the constrained Markdown-compatible path
  selected by ADR-0015. M18 recognizes document, heading, paragraph, list, fence,
  directive, inline, and reference boundaries; all unsupported or malformed
  regions are lossless `ERROR`/`OPAQUE` content, not rejected input.

## Data schemas

In `liminal-source`:

```rust
pub const MAX_SOURCE_BYTES: u64 = u32::MAX as u64;

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct SourceBasis {
    pub source: SourceId,
    pub content_hash: ContentHash,
}

#[derive(Debug, Clone)]
pub struct Utf8HolderView {
    pub basis: SourceBasis,
    text: ropey::Rope,
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum SourceLoadError {
    #[error("source exceeds rowan TextSize: {actual} > {maximum}")]
    TooLarge { actual: u64, maximum: u64 },
    #[error("source hash mismatch: expected {expected}, got {actual}")]
    HashMismatch { expected: ContentHash, actual: ContentHash },
    #[error("source is not UTF-8 at byte {valid_up_to}")]
    InvalidUtf8 { valid_up_to: u64, error_len: Option<u64> },
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum SourceSliceError {
    #[error("byte slice {start}..{end} exceeds source length {len}")]
    OutOfBounds { start: usize, end: usize, len: usize },
    #[error("byte offset {offset} is not a UTF-8 boundary")]
    NotCharBoundary { offset: usize },
}

impl Utf8HolderView {
    pub fn from_bytes(
        basis: SourceBasis,
        bytes: &[u8],
    ) -> Result<Self, SourceLoadError>;
    pub fn basis(&self) -> &SourceBasis;
    pub fn len_bytes(&self) -> usize;
    pub fn byte_slice(
        &self,
        range: std::ops::Range<usize>,
    ) -> Result<ropey::RopeSlice<'_>, SourceSliceError>;
    pub fn to_string(&self) -> String;
}
```

`Utf8HolderView::from_bytes(basis, bytes)` verifies the byte length, verifies
`ContentHash::of(bytes) == basis.content_hash`, validates UTF-8, and constructs
the rope. The view exposes `len_bytes`, `byte_slice`, `to_string`, and `basis`; it
exposes no mutation API.

In `liminal-cst`:

```rust
pub const MAX_NESTING: u16 = 256;
pub const MAX_ERRORS: usize = 1024;

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub enum LiminalLanguage {}

#[repr(u16)]
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub enum SyntaxKind {
    Root, Heading, Paragraph, List, Fence, Directive, Inline, Reference,
    Text, Whitespace, Comment, Delimiter, Attribute, Newline, Opaque, Error,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ParseError {
    pub code: ParseErrorCode,
    pub range: SourceRange,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ParseErrorCode {
    NestingLimit, ErrorLimit, UnclosedDelimiter, InvalidAttribute,
    InvalidReference, UnsupportedConstruct,
}

#[derive(Debug, Clone)]
pub struct Parse {
    green: rowan::GreenNode,
    errors: Vec<ParseError>,
    basis: SourceBasis,
}

pub type SyntaxNode = rowan::SyntaxNode<LiminalLanguage>;

pub fn parse(source: &Utf8HolderView) -> Parse;

impl Parse {

    pub fn errors(&self) -> &[ParseError];
    pub fn basis(&self) -> &SourceBasis;
    pub fn emit_lossless(&self) -> String;

```

`LiminalLanguage` implements `rowan::Language<Kind = SyntaxKind>` with checked
raw-kind conversion. `Parse::syntax()` returns the typed root; `errors()` is in
`(range.start, range.end, code)` order; `emit_lossless()` concatenates source-order
token text and returns `String`. Every public item, field, method, enum variant,
alias, and constant shown above receives a doc comment citing v4 §5.3, §9, or
§22 as applicable; these citations are part of the schema.

The constrained Markdown-compatible block grammar is:

```ebnf
document  = [ bom ], { blank | heading | list | fence | directive | paragraph } ;
bom       = U+FEFF ;
blank     = spacing, newline ;
heading   = hashes, " ", inline, line_end ;
hashes    = "#" | "##" | "###" | "####" | "#####" | "######" ;
list      = list_item, { list_item } ;
list_item = "- ", inline, line_end ;
fence     = "```", { codepoint - newline }, newline,
            { codepoint }, fence_close ;
fence_close = line_start, "```", spacing, line_end ;
directive = "::: ", ident, line_end, { paragraph | list },
            line_start, ":::", spacing, line_end ;
paragraph = paragraph_line, { paragraph_line } ;
paragraph_line = inline, line_end ;
inline    = { code_span | strong | emphasis | reference | text_char } ;
code_span = "`", { codepoint - "`" - newline }, "`" ;
emphasis  = "*", { code_span | reference | plain_char }, "*" ;
strong    = "**", { code_span | reference | plain_char }, "**" ;
reference = "[", { code_span | strong | emphasis | reference_char }, "](",
            destination, ")" ;
destination = { codepoint - ")" - control - whitespace } ;
text_char = codepoint - "`" - "*" - "[" - newline ;
plain_char = codepoint - "`" - "*" - "[" - newline ;
reference_char = codepoint - "]" - newline ;
ident     = ( ALPHA | "_" ), { ALPHA | DIGIT | "_" | "." | ":" | "-" } ;
spacing   = { " " | "\t" } ;
newline   = "\n" | "\r\n" ;
line_end  = newline | eof ;
```

`line_start` means byte zero or the byte after `newline`. A block marker is
recognized only at `line_start`; otherwise its bytes are paragraph text.
`paragraph` ends before blank, heading, list, fence, or directive start. Inline
parsing is left-to-right with precedence code span, strong, emphasis, reference,
then text; delimiters do not cross a newline. An unmatched inline delimiter is
plain `Text`. An unclosed fence or directive is one `Error` node through EOF with
the opening delimiter retained. A malformed block marker is one `Opaque` line.
Nesting and diagnostic saturation follow D18.3 and Algorithm 4 exactly.

## Algorithms

1. `Utf8HolderView::from_bytes` computes `actual_len`; reject above
   `MAX_SOURCE_BYTES`; compute and compare the content hash; run
   `std::str::from_utf8`; then build `Rope::from_str`. Freeze these checks in the
   existing malformed-source gate's oversized/hash/invalid-UTF-8 cases.
2. Coarse-scan rope chunks without flattening the source. Record byte boundaries
   for headings, paragraphs, lists, fences, directives, and opaque regions; every
   boundary is a UTF-8 boundary and a valid `SourceRange`.
3. Feed token text to one `GreenNodeBuilder` in source order. Maintain an explicit
   stack capped at `MAX_NESTING`; on overflow, emit one `NestingLimit` error and
   retain the affected input as `Opaque` tokens until the matching boundary.
4. Recover locally from malformed syntax by wrapping the original tokens in an
   `Error` node. Once `MAX_ERRORS` is reached, append one `ErrorLimit` diagnostic
   and retain the remaining region as one `Opaque` node. No recovery path changes
   token text.
5. Implement `emit_lossless` as the ordered concatenation of every token under the
   root. The existing gate catches panics and asserts output bytes equal input for
   valid, boundary, truncated, malformed, hostile, nesting-limit, and error-limit
   UTF-8 fixtures.

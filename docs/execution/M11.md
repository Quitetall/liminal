## Pre-made decisions

- **D11.1 — coalescing constant `COALESCE_GAP_MS = 2000`** (§7.4 names the rule,
  not the constant; frozen by the golden): consecutive `buffer_edit` on the same
  buffer with logical gaps < 2000 ms and NO intervening event of any other type →
  one semantic transaction. Boundary cases in the golden: gap 1999 coalesces, gap
  2000 splits, an interleaved `save` splits.
- **D11.2 — session constant `SESSION_TIMEOUT_MS = 1_800_000`** (30 min, §7.4
  verbatim). Explicit open/close wins; otherwise first activity opens, a ≥30-min
  gap in that client's activity closes at the previous event. Workspace-stream
  events attach to every session active at their `at` for incident accounting;
  outside any session they count in the corpus-wide op denominator but no session
  metric.
- **D11.3 — root-cause coalescing reuses D05.5's key grammar**
  (`<category>:<key>`, e.g. `git:merge@420000`): all user-visible surfaces
  sharing one key within one session = ONE visible incident;
  `max_visible_incidents_per_root_cause` = max over `(session, key)` — must be
  ≤ 1 to graduate.
- **D11.4 — auto-resolved numerator (R4 §2.3):** an op counts iff replay reaches
  the profile's declared stable outcome with zero manual-intervention surfaces,
  zero unexpected reconciliation items, zero diagnostics, and no fallback to an
  UNDECLARED Overlay. Profile-declared transient drafts (saves during
  `holder_unavailable`) are excluded from both numerator and denominator → the
  side `TransientDraftReport { declared, reconciled_within_window,
  aged_into_debt }`.
- **D11.5 — trace parser rejects unknown fields** (`deny_unknown_fields`) —
  corpus defects fail loudly.
- **D11.6 — NO new `lim` subcommand.** Conformance bins instead: `scorecard`
  (AM-11.2) and `gen-manifest` (AM-11.1); generators in `tracegen` (AM-11.3).
- **D11.7 — the locking ceremony order is BINDING:** assemble → gen-manifest →
  commit → flip the denominator golden → ONLY THEN one scorecard run per profile
  on heldout/v1, recorded to `conformance/golden/scorecard-heldout-v1.json` → v1
  frozen forever. Debugging failures happens by reproduction in `fixtures/` or
  minimization into `corpora/regression/` — never by reading held-out traces.

## Data schemas

NDJSON, one JSON object per line, `serde(tag = "type", rename_all =
"snake_case")`. Every event has `at: u64` (logical ms, monotone nondecreasing).
Root-cause-capable events carry `cause_category` + `cause_key`; derived events
repeat the SAME pair.

| type | fields |
|---|---|
| `trace_header` (line 1, mandatory) | `version: 1`, `trace_id`, `source`, `capture_tool`, `consent: "consented-anonymized"\|"synthetic"\|"public-git"`, `profile`, `setup: { files: [{path, contents}], graph: […M03 setup tables…] }` |
| `session_open` / `session_close` | `at`, `session`, (`client` on open) |
| `buffer_open` | `at`, `session`, `client`, `buffer`, `path` |
| `buffer_edit` | `at`, `session`, `buffer`, `range: {start, end}` (byte splice), `insert` |
| `save` | `at`, `session`, `buffer` |
| `file_change_external` | `at`, `path`, `contents` (full new bytes; toy scale), `cause_category: "foreign"\|"formatter"\|"git"`, `cause_key` |
| `git_op` | `at`, `op: "commit"\|"merge"\|"rebase"\|"cherry-pick"\|"checkout"`, `files: […]`, `cause_category: "git"`, `cause_key: "<op>@<at>"` |
| `formatter_rewrite` | `at`, `path`, `contents`, `tool`, `cause_category: "formatter"`, `cause_key: "<tool>@<at>"` |
| `holder_unavailable` / `holder_available` | `at`, `holder` (+ cause pair on unavailable: `"holder"`, `"<holder>@<at>"`) |
| `resolver_observe` | `at`, `source`, `observed`, `cause_category: "resolver"`, `cause_key: "<source>@<at>"` |
| `clock_advance` | `at` only — a pure logical-time jump; a jump ≥ 30 min splits sessions |

## Algorithms

### A. Event → Jurisdiction-sensitive-operation counting (every type decided)

| event | ops counted |
|---|---|
| trace_header, session_open/close, clock_advance | 0 |
| buffer_open | **1** (a read choosing Holder + Basis) |
| buffer_edit | 0 individually; **each semantic transaction = 1** |
| save | **1** (Promotion = repair) |
| file_change_external | **1** — **0** if its `(cause_category, cause_key)` matches a prior `git_op` (it is the byte delivery of an already-counted op) |
| git_op | **len(files)** (one foreign-edit ingestion per affected file) |
| formatter_rewrite | **1** |
| holder_unavailable | 0 |
| holder_available | **1 per Overlay reconciliation attempted** on Holder return |
| resolver_observe | **1** |

### B. Importers / generators (`tracegen` bin, five subcommands)

- `tracegen git <op-script> <out>` — M07 hermetic runbook; replay an M07 op
  script; walk `git log --reverse` diffs; step k → `at = k × 60_000`; each op →
  one `git_op` + one `file_change_external` per changed file (same cause pair).
  Header: `source: "m7-script:<name>"`, `consent: "synthetic"`.
- `tracegen session <session.toml> <out>` — expands scenario-style TOML into
  open/buffer/edit/save/close with an `at` schedule (per-step `dt`, default
  500 ms). Dev stand-in; held-out instances come from independently supplied
  scripts (POLICY: never authored by the profile author).
- `tracegen formatter <fixture-dir> <out>` — deterministic rewrites (M07 op 7
  vocabulary) → `formatter_rewrite` events.
- `tracegen offline <out>` — `holder_unavailable` → edits + save (durable
  Overlay) → `clock_advance` past the window → `holder_available`; drives the
  transient-draft/aging path for the third slo test.
- `tracegen adversarial <m7-op> <seed> <out>` — M07 identity-torture ops replayed
  as `file_change_external {cause_category:"foreign"}` — independent because
  generated by the identity lab, not tuned by profile authors (R4 §2.2).

### C. Pipeline (`conformance/src/{trace.rs, denominator.rs, pipeline.rs}`)

`pipeline::run(corpus_dir, profile) -> (Scorecard, TransientDraftReport)`:
1. Per trace: build `ToyWorkspace` from `trace_header.setup`; replay events
   through the M03/M05 runner (`session_open→open_session`,
   `buffer_open→open_buffer`, `buffer_edit→edit`, `save→save`,
   `file_change_external|formatter_rewrite→apply_foreign_change`,
   `holder_*→set/clear + sweep`, `resolver_observe→inject_observation`,
   `clock_advance→advance_clock`).
2. Collect observables per event: checker output bytes, diagnostics,
   reconciliation items (expected vs unexpected, keyed by cause),
   contract-authoring prompts, overlay dispositions.
3. Apply A + D11.1–D11.4 → all nine frozen Scorecard fields per profile.
4. The side `TransientDraftReport`.

### D. Corpus assembly + lock (runbook)

- `conformance/corpora/dev/` — freely editable, NOT locked; ≥2 traces per
  generator per profile, `*.trace.ndjson`.
- Hand-labeled denominator traces:
  `conformance/fixtures/traces/labeled/{coalesce-basic, session-timeout,
  git-rootcause, offline-transient}.trace.ndjson` + expected-counts golden —
  these freeze D11.1–D11.3 BEFORE any tuning.
- heldout/v1: generate with seeds DISJOINT from dev (seeds recorded in each
  header); git traces from M07 scripts not used in dev + ≥1 imported real
  public-repo history (provenance in header); place under
  `conformance/corpora/heldout/v1/`; run `gen-manifest` (walks the tree, BLAKE3
  per file, writes `MANIFEST.b3` sorted, excluding itself; output must
  round-trip `verify_heldout_manifest` — tested); commit; ceremony per D11.7.

## Amendments

- AM-11.1: conformance `[[bin]] gen-manifest`.
- AM-11.2: conformance `[[bin]] scorecard`.
- AM-11.3: conformance `[[bin]] tracegen`.
(Bins are invocable surface — flagged even though the crate is publish=false.)
- AM-11.4: `liminal_daemon::runner::StepRunner` — Algorithm C step 1 says
  "replay events through the M03/M05 runner" and step 2 "collect observables
  PER EVENT", but the runner's only public entry (`exec`) ran a whole
  scenario atomically: per-event observation was impossible without either
  duplicating the save/foreign-edit semantics in the conformance crate
  (poisonous: the pipeline would measure a second implementation) or a
  public per-step seam. Additive refactor: `exec`'s setup + step-loop body
  moves verbatim into `pub struct StepRunner` (`open`/`open_buffer`/`step`/
  `workspace`/`workspace_mut`/`root`); `exec` delegates and is
  behavior-identical (full workspace suite incl. the derived crash matrix
  green before landing). `open_buffer` is the one NEW capability — a
  mid-stream buffer registration over current durable bytes, needed for the
  trace `buffer_open` event; at time zero it is exactly `exec`'s
  setup-buffer seeding. Call sites: `runner::exec` (delegation),
  `conformance/src/pipeline.rs` (M11.5).

- AM-11.5 (M11.7 prep): `tracegen import <repo-dir> <out> --source <provenance>
  [--max-commits <n>] [--ext <list>]` — the Algorithm D real-public-repo
  importer. First-parent walk oldest-first (the trace models a workspace
  tracking the default branch; a merge delivers its full mainline diff as one
  `git_op`); base commit → setup.files; deleted paths counted in `git_op.files`
  but never delivered (no bytes exist); non-UTF-8 blobs skipped with the count
  recorded in the header `source` (no silent caps); `Consent::PublicGit`. Path parsing uses NUL-separated (`-z`) git output
  throughout — real histories contain committed filenames with trailing
  whitespace (tldr's early `ls.md   `) that line-based parsing corrupts.

## Discovered gaps

- DG-11.1: Algorithm A's `holder_available` row ("1 per Overlay
  reconciliation attempted on Holder return") is not literally computable
  from the trace alone without a reading of what a "Holder" identifies.
  `denominator.rs` reads it as: Phase -1's only Holder is the file path
  (D05.1: `SYS_UNAVAILABLE[path]`; `runner::holder_available(store, path)`;
  Algorithm C step 1 maps trace `holder_*` events onto exactly these
  functions), so the trace's `holder` field IS the path. The op count is
  then the number of DISTINCT paths that received a `save` while that path
  was unavailable and have not yet been reconciled (matching D05.3: a second
  offline save to the same subject coalesces into the SAME Overlay, not a
  second one). This is a T2 engineering reading, not spelled out verbatim by
  the order; `pipeline.rs`'s actual replay (M11.5) is the authoritative
  cross-check and should confirm or correct this before `denominator_counts_golden`
  freezes (M11.3). Does not block M11.1/M11.2: no boundary test we own
  exercises `holder_available` counting.
  **Ratified at M11.3 (T1 ruling): one reconciliation per distinct
  pending-draft path, per D05.3. Cross-checked at M11.5:**
  `pipeline::tests::dg11_1_replay_reconciliation_attempts_match_frozen_denominator`
  replays the `offline-transient` labeled fixture through the REAL runner
  (AM-11.4 seam) and asserts, per `holder_available` event, that the number
  of Overlay reconciliations actually attempted on Holder return equals the
  frozen per-event denominator count — **replay AGREES with the frozen
  reading** (1 attempted == 1 counted). The test stays in the suite as a
  standing guard; any future divergence is a T1 escalation, never a silent
  fix.
- DG-11.2: D11.2's explicit/implicit session-boundary rule is unambiguous
  when a `session` id has BOTH an explicit `session_open` and a matching
  `session_close` (bracket wins outright, no internal splitting) or NEITHER
  (fully implicit: first-activity/30-min-timeout derivation). A PARTIAL
  bracket — only `session_open` with no matching `session_close`, or vice
  versa — is not spelled out. `denominator.rs` treats a present bookend as a
  hard boundary on its own end and derives the other end via the
  first-activity/timeout rule. None of the M11.2 labeled fixtures or
  boundary tests exercise this partial case; flag for confirmation before
  M11.3's golden freezes.

- **DG-11.3 (M11.7 probe, RESOLVED).** Replaying an imported real history
  failed on any file ADDED after setup (`pipeline.rs` read the current bytes
  to build the whole-content `foreign_edit`, and a new file — often in a
  directory that never existed at setup — has none). Found by the mandatory
  pre-ceremony probe (150-commit tldr slice), NOT in any dev trace (all
  fixture worlds pre-declare their files). Resolution: a missing path is a
  foreign ADD — create parents + empty file, then the `find:""` whole-content
  replace lands the bytes through the same runner step. Regression:
  `m11::imported_trace_with_added_nested_file_replays`.

## Pre-made decisions

- **D01.1 — firing mechanism = hidden `liminald __fire <point> [count]` subcommand**
  (AM-1.1). `liminald exec` does not exist at M1 and Cargo cannot build a
  `#[cfg(test)]` binary. A separate helper bin would construct the injector through
  a second code path, weakening the proof; `__fire` exercises the exact production
  `EnvCrashInjector::from_env()` path.
- **D01.2 — test location = `crates/liminal-daemon/tests/crash.rs`** because
  `CARGO_BIN_EXE_liminald` is only injected for the crate that owns the `[[bin]]`.
- **D01.3 — test names carry the `crash_` prefix** (AM-1.2) so the nextest
  serialized crash group matches; the implementation-plan shorthand
  `fault_abort_exits_with_sigabrt` ≡ `crash_fault_abort_exits_with_sigabrt`.
- **D01.4 — `const SIGABRT: i32 = 6`** in the test file with a comment: Phase -1
  targets Unix dev machines (Linux/macOS); Windows crash semantics are a Phase 2
  concern with the real-daemon SIGKILL handshake.

## Algorithms

`__fire` handler: resolve `point` via
`CrashPoint::all().into_iter().find(|p| p.name() == point)` (else
`anyhow::bail!("unknown crash point: {point}")`); build
`EnvCrashInjector::from_env()`; loop `count` times (default 1) calling
`crash_if_armed(p)` (import `liminal_jurisdiction::CrashInjector as _`); exit 0,
no output on success.

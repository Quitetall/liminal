## Data schemas

Spike 1:

```rust
pub struct Annotation { pub id: u32, pub range: SourceRange, pub kind: AnnKind, pub payload: String }
pub enum AnnKind { Mark, Link, Comment }
pub struct AnnotatedDoc { pub text: String, pub annotations: Vec<Annotation> }
```

Each annotation carries one M07 `Anchor`; after every foreign edit, re-anchor →
per-annotation outcome ∈ {Exact, Shifted(conf), Ambiguous, Lost}. Projection:
paragraphs → PARAGRAPH nodes, annotations → Relations with `Target::Anchored`.

Spike 2 op set: `insert_text{block, offset, text}`, `delete_range{block, range}`,
`add_mark{block, range, kind}`, `split_block{block, offset}`,
`join_block{block}`, `undo`.

Graph-op mapping:

| editor op | graph transaction |
|---|---|
| insert_text / delete_range | `SetPayload(node, new_text)` |
| add_mark | `AddRelation` (mark Relation, `Target::Anchored`) |
| split_block | `CreateNode(new)` + `SetPayload(first-half)` + `InsertChild(parent, new, i+1)` + retarget Relations whose anchor falls in the second half |
| join_block | `SetPayload(first, joined)` + retarget second's incoming Relations → first (grade check via Q4) + `DeleteNode(second)` |
| undo | inverse transaction from recorded inverse ops — never byte restoration (R4 §11.3 spirit) |

Report format (`conformance/golden/anchor_recovery.md`):

```
# Anchor recovery report (Phase -1.2, M9)

box: 2026-MM-DD .. 2026-MM-DD (hard 2-week box)
config: blake3:<hex of M7 config.toml>   git: <exact version>   seeds: 8

| operation class | recovery % | identity % | undo fidelity % |
|---|---|---|---|
| rename_move | 100.0 | 100.0 | n/a |
…(11 foreign-op rows, then 6 rich-edit-op rows)…

declared level: <0|1|2|3>
```

One decimal place; fixed row order (M07 `operations.enabled` order, then the
spike-2 op order above). Dimensions: **recovery%** = annotations Exact|Shifted /
total; **identity%** = tracked paragraphs whose entity survives per
anchor/structural rules / total; **undo-fidelity%** = byte+graph-faithful undos /
undos attempted (`n/a` on foreign rows).

## Algorithms

The measurement loop, per operation class: (1) build the annotated base doc from
the M07 template (3 annotations per block: one Mark, one Link, one Comment at
seeded ranges); (2) apply the operation (foreign classes via the M07 script;
rich-edit classes via the spike-2 op set); (3) re-anchor every annotation through
the M07 five-step ladder → tally recovery; (4) re-ingest and grade entity
survival via the M07 structural rule → tally identity; (5) rich-edit rows only:
apply `undo`, compare bytes AND graph state to pre-op → tally fidelity;
(6) accumulate per class across 8 seeds; render per the report format. The level
computation (D09.4) runs over the finished table and is the same function
`declared_level_matches_report` re-runs.

## Pre-made decisions

- **D10.1 — AST encoding:**

  | Toy construct | Pandoc JSON | Markdown round-trip form |
  |---|---|---|
  | document | `{"pandoc-api-version":[1,23,1],"meta":{},"blocks":[…]}` | n/a |
  | paragraph, no `{#id}` | `Para [Str/Space…]` | plain paragraph |
  | paragraph with `{#id}` | `Div ("<id>",[],[]) [Para […]]` | fenced div `::: {#id}` |
  | comment Relation | **none — DECLARED loss** (`may_discard`) | dropped at emit |
  | foreign-node probe | `RawBlock ("html","<!--liminal:probe-->")` | raw HTML passthrough |

  Justification: `Para` carries no Attr in the Pandoc AST; `Header` attrs would
  lie about block kind; `Div` is Pandoc's only attributed block container and
  round-trips losslessly through the markdown writer/reader as a fenced div, so
  ID survival is a real measurement. Inline encoding: text split on whitespace →
  alternating `Str`/`Space`; reimport flattens `Str`→text,
  `Space`/`SoftBreak`→`" "`.
- **D10.2 — pipeline:** emit Pandoc JSON directly (no no-op json→json pass);
  `pandoc -f json -t markdown-smart --wrap=none -o roundtrip.md ast.json` then
  `pandoc -f markdown-smart -t json -o ast2.json roundtrip.md`. `-smart` both
  directions so typographic rewriting doesn't pollute structural-loss numbers;
  `--wrap=none` so wrapping doesn't pollute text fidelity. API version hardcoded
  `[1,23,1]` (pandoc-types for 3.6.x).
- **D10.3 — version pin:** `pandoc --version` first line must equal
  `pandoc 3.6.1`; missing binary or version mismatch →
  `panic!("M10 requires pandoc 3.6.1 (pacman -S pandoc); found {…}. Update the
  pin + regenerate the golden if intentionally upgrading.")`. **No silent skip,
  no `#[ignore]`** — a skipped loss report would fake Law 8. (This machine has
  `/usr/bin/pandoc`; CI must install it or fail loudly — intended.)
- **D10.4 — Level rule:** the adapter declares **Level 1** iff blocks, order,
  text, and id survival are all 100% AND every non-surviving construct appears in
  the transform contract's `may_discard`. Any dimension < 100% and undeclared →
  Level 0 for that construct class and the gate fails. Level 2 is NOT declared
  (comment Relations don't survive); paragraph-subset second-pass stability
  (`markdown → json → markdown` byte-stable) is recorded as informative only.

## Algorithms

Measurement procedure: (1) ingest the fixture through the M03 grammar + setup
vocabulary → toy doc + 2 comment Relations; (2) `emit` → `ast.json` (D10.1
mapping, probe RawBlock appended); (3) run the D10.2 pipeline → `roundtrip.md` →
`ast2.json`; (4) `normalize` both ASTs → `Vec<(Option<id>, text)>`; (5) compute
the six dimensions (block count; positional order+text; positional id survival;
relation loss = declared by construction; probe byte-identity); (6) render the
report; (7) compute the declared level via D10.4 — the same function
`declared_level_matches_loss_report` re-runs.

report records the TRUE survival rate and the declared level drops — the gate
then fails and that IS the measurement. Record here; do not patch the encoding to
hide it.

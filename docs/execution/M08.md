## Data schemas

`GraphStore` additions (`crates/liminal-graph/src/store/asof.rs`):

```rust
impl GraphStore {
    /// As-of read: replay retained segments from genesis into a scratch State,
    /// stopping after the record with revision == rev. The toy never GCs
    /// segments, so genesis replay is always available; O(n) is toy-fine.
    pub fn state_at(&self, rev: GraphRevisionId) -> Result<StateView, StoreError>;
}
pub struct StateView { /* owns a State materialized at rev */ }
impl StateView {
    pub fn node(&self, id: NodeId) -> Option<&Node>;
    pub fn relation(&self, id: RelationId) -> Option<&Relation>;
    pub fn relations_from(&self, source: NodeId) -> Vec<&Relation>;
    pub fn children(&self, parent: NodeId) -> &[NodeId];
    pub fn get_aux(&self, ns: &str, key: &str) -> Option<&serde_json::Value>;
    pub fn head(&self) -> GraphRevisionId;
}
```

(Internal `SegmentLog::replay_range` helper reuses `replay_segment`.
`node_at`/`relation_at`/`relations_from` keep the in-memory fast path at head and
delegate to `state_at` for `rev < head`.)

```rust
pub enum Durability { Immutable, High, Medium, Low, Ephemeral }   // v4 §24.1 verbatim
pub fn durability(c: &BasisComponent) -> Durability {
    match c {
        ObjectContent{..} | GitCommit{..}      => Immutable,
        FileContent{..} | GraphSnapshot{..}    => Medium,
        BufferGeneration{..} | Observation{..} | ExternalRevision{..} => Low,

}
```

Doc note verbatim from §24.1: durability is an invalidation optimization, not
truth or freshness. Used only to order the cache's staleness checks (Low first);
a unit test asserts the table is total.

## Algorithms

### A. The four queries (`liminal-daemon/src/queries.rs`, each `impl liminal_query::Query`)

| Query | Output | Reads / records |
|---|---|---|
| `RenderBlock { node }` | `String` — `"{alias}: {text}\n"` (alias omitted when none) | text from the perspective-selected component for the owning file: buffer blob (`SYS_BLOB["buf/<c>/<b>/<g>"]`) or file blob; records `Path(file)`; alias from graph → records `graph_key()` |
| `Backlinks { node }` | `Vec<RelationId>` sorted | `state_at(GraphSnapshot.revision)` relations targeting node; records `graph_key()` |
| `WorkspaceExport` | `String` — all files, blocks re-emitted in child order with `{#id}` markers, `\n\n` separators | every `FileContent` component + graph; records each `Path(p)` + `graph_key()` |
| `AiContextStub { focus }` | canonical JSON `{"focus","text","neighbors":[…],"basis":{"transaction","perspective"}}` | focus text per RenderBlock rule + neighbor blocks via graph; records those keys |

### B. Inject flow (one transaction)

1. `hash = ContentHash::of(canonical payload bytes)`.
2. `put_aux(SYS_BLOB, "obs/<source>/<hash>", payload)`.
3. `Operation::MaterializeExternal { node: external-value node, source, observed: hash, at }`; commit.
4. `AvailableInputs.durable[Source(source)] = Observation { source, observed_at, hash }`.

Scenario step `resolver_observe` fields:
`{ source = "stock:acme", price = 42.17, at = "2026-01-01T00:00:00Z" }`.

### C. Freeze/replay harness (`conformance/src/replay.rs`)

`freeze(basis, workspace) -> String`: canonical JSON (BTreeMap ordering) of
`{ basis, blobs: { <component key>: bytes } }` where blobs carries, for every
component, the exact bytes it pins (buffer blob, file bytes, observation payload,
and the serialized `state_at(revision)` State for the graph component).
`FrozenWorld::load(&str)` serves reads purely from that JSON. Test flow: run the
scenario → capture the 4 outputs → freeze each basis → **delete the workspace
directory** → re-execute the four queries against `FrozenWorld` → byte-identical
outputs (final-gate requirement).

## Discovered gaps

- **DG-8.1 (M08.6, source name → `SourceId`).** The scenario's
  `resolver_observe` uses `source = "stock:acme"`, but `SourceId` is a UUID
  newtype with no string mapping; `BasisComponent::Observation.source` is typed
  `SourceId`. **Resolution:** `SourceId::from_name(name)` derives a STABLE id via
  UUIDv5 (`NAMESPACE_OID`, name bytes) — deterministic across runs/machines, so a
  frozen Basis replays byte-identically (v4 §42). The blob key `obs/<source>/<hash>`
  uses the derived id's Display form. Recorded as AM-8.4.

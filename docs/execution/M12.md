## Discovered gaps

- **DG-12.1 — RESOLVED BY AM-12.3.** `four_consumers` materializes an
  EXTERNAL_VALUE Node, but M03's older kind dispatch returned Ungoverned. Final
  gate test 1 found it by enumerating every scenario subject.
- **DG-12.2 — RESOLVED BY AM-12.4.** M12 freezes test 7's name with the same
  token M05 prohibits. Exact coordinate allow-listing preserves the sweep while
  permitting the mandated absence-assertion name.
- **DG-12.3 — RESOLVED.** Q1 buffer capture scanned any matching client buffer
  without first proving the subject uses the external-file profile and that the
  component belongs to its owning path. Graph-native subjects can therefore
  resolve to `Holder::Buffer` under a client-scoped Basis. Resolution: capture
  only when the contract's durable Holder is that exact File path.
- **DG-12.4 — RESOLVED.** `AvailableInputs.durable[Source(source)]` was updated
  only in memory. Reopening a workspace reconstructs file components but drops
  every durable Observation. Resolution: commit `obs-current/<source>` metadata
  with materialization and reconstruct the component at open.
- **DG-12.5 — RESOLVED.** Freeze substituted JSON null for absent buffer or
  observation blobs and does not verify their pinned content hashes, permitting
  a deterministic replay of bytes the Basis never named. Resolution: absence,
  non-text buffer data, and hash mismatch now fail closed.
- **DG-12.6 — RESOLVED.** First observation created its EXTERNAL_VALUE node in
  one transaction and materialized the observation in a second, violating M08's
  one-transaction inject flow. Resolution: first-node creation, blob writes,
  current-observation metadata, and materialization share one commit.
- **DG-12.7 — RESOLVED.** The four-consumer scenario executed query steps, but
  its integration gate never reads the runner-persisted query outputs; direct
  query calls could pass while runner wiring regressed. Resolution: the M08 gate
  reads all four persisted outputs and cross-checks three against direct queries.
- **DG-12.8 — RESOLVED.** The final undo gate proved only that reverted bytes
  differ from repaired bytes, not that they equal the recorded preimage. Both
  revert gates now compare bytes to the inverse plan's exact preimage.
- **DG-12.9 — RESOLVED.** The crash matrix iterated returned terminal states
  without requiring any terminal, so recovery that silently drops every intent
  could pass vacuously. Baseline hits and first-recovery terminals must be
  non-empty before matrix assertions proceed.
- **DG-12.10 — RESOLVED.** Gate 9 treated a nonzero manifest byte length as a
  non-empty held-out corpus; whitespace-only manifest content with an empty tree
  passed the verifier and this assertion. The verifier now rejects an empty
  parsed manifest, proven against a synthetic empty directory.
- **DG-12.11 — RESOLVED BY LEDGER BACKFILL.** ADR-0008 omitted AM-3.1,
  AM-4.1–4.3, AM-5.1, and AM-6.1–6.2 even though their work orders recorded
  them. M12 reconciled those seven entries before omnibus ratification.
- **DG-12.12 — RESOLVED AT M12.5.** `phases.md` requires a future phase's gate
  tests to exist as ignored backlog at the preceding gate. M12.5 therefore
  authored the 18-test Phase 0 surface with M13–M17; after the M12.4 historical
  closeout count and the two meter regression tests, the live meter becomes 219
  active and 39 deferred, including 18 Phase 0 tests.
- **DG-12.13 — RESOLVED BY ADR-0014.** The debt scanner counted `#[test]` before
  seeing a following `#[ignore]`, so every deferred test also inflated the active
  count. TDD regressions now require reasoned ignores to be deferred only and bare
  ignores to surface as unphased debt. Corrected M12.4 evidence is 217 active / 21
  deferred; Phase -1 backlog and the GO decision are unchanged.
- **DG-12.14 — RESOLVED BY PROTOCOL CLARIFICATION.** Phase 0's preceding-gate
  ignored backlog and shared `phase0.rs` target exposed Phase -1-specific wording
  that otherwise prohibited both. Section 1 now distinguishes preceding-gate
  stubs from forbidden mid-milestone ignores; §8 assigns shared Phase 0+ gates.
- **DG-12.15 — RECORDED PROCESS DEVIATION.** Fixed-point review found that commits
  `88c2961`, `4044360`, `185c94a`, `3b0c757`, `7aa36f9`, `49e4b1e`, `6354838`,
  and `38ef776` did not all satisfy the preferred singular-amendment or step/area
  subject plus spec-citing body convention, and `3b0c757` grouped the approved
  remediation package. History is not rewritten; this entry preserves the
  deviation and later commits follow §6 exactly.
- **DG-12.16 — RESOLVED IN M13.** The first six-domain topology draft named new
  live kinds and an attribute map that existing dispatch could not govern or
  lower. M13 now freezes domain roles as fixture-only labels, uses only
  FILE/PARAGRAPH/EXTERNAL_VALUE plus Relations, stores typed metadata as canonical
  payload JSON, and declares expected governance per subject.
- **DG-12.17 — RESOLVED BY PHASE LEDGERS.** The Phase -1-only amendment procedure

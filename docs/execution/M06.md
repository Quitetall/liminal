## Pre-made decisions

- **D06.1 — `resolve()` reads ONLY the requester's working map** — Law 3J by
  construction, not by filtering.
- **D06.2 — ambiguity is handled at PUBLISH time, not resolve time** (the frozen
  `working` map holds one component per key): when a client opens a SECOND
  divergent buffer over an already-buffered path with no selection, the daemon
  (a) removes `working[client][key]` (subject falls back to durable — v4 §7.5) and
  (b) upserts one coalesced `ambiguity:client:<uuid>:path:<p>` item.
  `ClientSession::select_working` (AM-6.2) records the selection, republishes that
  buffer's component, and resolves the item.
  `PerspectiveError::AmbiguousWorkingHolder` remains the guard for the
  inconsistent state (selection names a buffer other than the published one — a
  bug, surfaced loudly).
- **D06.3 — epoch source:** `ToyWorkspace::open` bumps `SYS_EPOCH["epoch"]` by one
  (its own txn) → the process's `SessionEpoch`. Generation = per-buffer counter
  starting at 0.
- **D06.4 — buffer blobs at `SYS_BLOB["buf/<client>/<buffer>/<generation>"]`** so
  memoized queries can read exact generation bytes.
- **D06.5 — M04's private buffer map migrates into `AvailableInputs`** (single
  source of truth); `save` now captures a real `basis(ClientScoped{client})` and
  the M02 placeholder basis construction is deleted.
- **D06.6 — memo staleness is defined on component VALUES, not keys** (all three
  perspectives read `path:notes.md`; key equality cannot distinguish clients):
  an entry is stale ⇔ re-resolving its perspective yields, for some key in
  `deps.read`, a component ≠ the entry's captured `snapshot[key]`.

## Algorithms

### A. `resolve(inputs, perspective, at)` — every v4 §7.5 rule

```
1. components = match perspective:
   DurableOnly → inputs.durable.clone()                    // ignores ALL working claims
   ClientScoped{client}:
     a. base = inputs.durable.clone()
     b. for (key, comp) in inputs.working.get(client).unwrap_or_default():
        match inputs.working_selection.get(client).and_then(|m| m.get(key)):
          None → base[key] = comp                          // publisher guarantees uniqueness (D06.2)
          Some(sel) if comp is BufferGeneration{buffer == *sel} → base[key] = comp
          Some(_) → return Err(AmbiguousWorkingHolder{key, client})
        // other clients' maps are NEVER read — Law 3J by construction
     c. base
   Published{..} → Err(PerspectiveError::PublishedUnavailable)   // AM-6.1
   Federated{..} → Err(PerspectiveError::NoFederationFrontier)
2. Ok(WorkspaceBasis { transaction: at, perspective: perspective.clone(), components })
```

Requester-less consumers (exports, background jobs) never call `ClientScoped` —
the daemon's consumers pass `DurableOnly` explicitly; the fail-closed rule is
asserted by the M12 gate test.

### B. Buffer generation production

`open_buffer(path)`: mint `BufferId`; read file → `H_base`; persist
`SYS_BLOB["buf/<c>/<b>/0"]`; register buffer state; publish
`working[client][Path(p)] = BufferGeneration { client, buffer, epoch,
generation: 0, content_hash: Some(H_base), base_file_hash: Some(H_base) }` — or
run the D06.2 ambiguity procedure. `edit(buffer, contents)`: `generation += 1`;
hash + persist blob; build the component; publish if this buffer is the
selected/only one; return it.

# M13 — Constitutional kernel and governed examples (v4 §§1–8, §19, Part XXII Phase 0)

**Status:** work order — 1.5 weeks. Authored at the M12 gate. The executor
implements mechanically; deviation = amendment or discovered gap, never silent.

## Scope

Turn `spec/kernel.md` from an index into a self-contained constitutional chapter,
publish the interpretive Contract and Workspace Basis rules, publish the tiered
vocabulary ceiling, and encode six governed representation examples. This order
does not build a parser, CST, compiled Jurisdiction plan, UI, or new semantic
primitive (`docs/implementation-plan.md` §4 items 1, 3, 10, 11, 12).

## Spec inputs

v4 §§1–8, §19, §43–48, §118A, Part XXII Phase 0; R4 §§1–3, §8, §10;
`docs/adr/0009-cap-identity-promises-at-phase-minus-1-evidence.md`;
`docs/adr/0013-phase-0-go-no-go-after-falsification-laboratory.md`; M03, M06,
M07, and M12.

## Frozen surfaces

Node and Relation are the only semantic primitives. Existing public Contract,
Holder, Basis, and identity-grade shapes remain reference semantics. Canonical
`spec/v4/**` files are immutable. Example IDs, test names, and fixture version 1
below are frozen once this order lands. No `FacetId` or third subject may appear.

## Pre-made decisions

- **D13.1 —** `spec/kernel.md` becomes normative, self-contained prose but cites
  canonical v4/R4 and accepted RFCs for authority; it does not copy Rust source.
- **D13.2 —** six examples use only Node and Relation with the exact topology
  table below: prose, code block, table, image reference, audio interval, and
  synchronized external value. A domain label alone proves nothing.
- **D13.3 —** every example names profile, Holder, and minimum identity grade;
  `Ungoverned` and implicit identity are invalid fixture states.
- **D13.4 —** user-facing vocabulary is domain-native. Jurisdiction, Holder,
  Overlay, and Promotion are an explanation ceiling, not routine UI text.
- **D13.5 —** external-file defaults to Anchored; graph-native and
  EXTERNAL_VALUE default to Managed, exactly as ADR-0009 and AM-12.3 freeze.

## Data schemas

`conformance/fixtures/phase0/representation-examples.toml`:

```toml
version = 1

[[example]]
id = "prose"
domain = "prose" # prose|code|table|image|audio-interval|external-value
profile = "external-file" # external-file|graph-native
holder = "file:examples/prose.md" # file:<path>|graph
minimum_identity = "anchored"

[[example.node]]
alias = "document"
kind = "document"
payload = ""
attributes = {}

[[example.node]]
alias = "body"
kind = "paragraph"
payload = "hello"
attributes = {}

[[example.relation]]
kind = "contains"
from = "document"
to = "body"
```

`attributes` is a string-to-string map with sorted unique keys. Each example has
non-empty, unique `id`; exactly one standard profile and concrete Holder; exact
nodes/relations required below; no unlisted node or relation kind; and relation
endpoints naming aliases in the same example. `minimum_identity` uses
`IdentityGrade` kebab-case spelling. Domain is closed to the six values for v1.

| Domain | Profile / Holder / grade | Exact required nodes | Exact required relations and payload constraints |
|---|---|---|---|
| prose | external-file / `file:examples/prose.md` / Anchored | `document`, `paragraph` | `contains(document, paragraph)`; paragraph payload non-empty |
| code | external-file / `file:examples/code.md` / Anchored | `document`, `code-block` | `contains(document, code-block)`; code payload non-empty; `language=rust` |
| table | external-file / `file:examples/table.md` / Anchored | `document`, `table`, two `row`, four `cell` | document contains table; table contains both rows; each row contains two cells; `next(row-1,row-2)`; every cell payload non-empty |
| image | external-file / `file:examples/image.md` / Anchored | `document`, `image-resource` | `embeds(document, image-resource)`; payload is `sha256:<64 lowercase hex>`; non-empty `mime` and `alt` |
| audio-interval | external-file / `file:examples/audio.md` / Anchored | `document`, `audio-resource`, `audio-interval` | document contains interval; interval references resource; resource payload is `sha256:<64 lowercase hex>`; canonical unsigned-decimal attributes satisfy `start_ms < end_ms` |
| external-value | graph-native / graph / Managed | `external-source`, `EXTERNAL_VALUE` | `materializes(external-source, EXTERNAL_VALUE)`; non-empty source ID, revision token, observation timestamp, and payload |

Validator compares aliases, kinds, relation triples, multiplicities, and listed
payload/attribute predicates exactly. Six copies of one topology with different
domain labels fail.

## Algorithms

1. Expand `spec/kernel.md` into normative sections for constitution, kernel,
   Jurisdiction Contract, Holder resolution, Workspace Basis/Perspectives,
   profile selection, identity, representation, and vocabulary. Every MUST maps
   to a live type, accepted ADR/RFC, or conformance assertion.
2. Load fixture v1 with `serde(deny_unknown_fields)` structs local to Phase 0
   conformance. Reject duplicate IDs/aliases, missing relation endpoints,
   unknown profiles/grades/domains, topology/multiplicity drift, invalid payload
   predicates, and non-concrete Holders.
3. Materialize each example through existing graph transactions and profile
   dispatch. Enumerate subjects through `Checker::subjects`; assert every subject
   resolves and meets declared minimum grade.
4. Compare each materialized example against the exact topology table, then
   assert state contains only Nodes and Relations. Search production Rust for
   prohibited facet identifier spellings using split needles so the prohibition
   test never allow-lists itself.

## Pre-made decisions

- **D02.1 — every durable state change is its own aux-commit, and `run` is
  resumable via ONE internal `advance` fn shared verbatim with `recover_all`.**
  Run and resume become a single audited code path; there is no separate "resume
  interpreter" to drift.
- **D02.2 — the intent record is KEPT at `state = committed`** — it is the durable
  history behind `lim repairs`. Deletion is forbidden.
- **D02.3 — `FsExecutor` lives in `crates/liminal-daemon/src/executor.rs`**:
  `liminal-jurisdiction` stays Holder-agnostic interpretive semantics; the file
  executor is a Holder adapter and the daemon is the assembly crate.
- **D02.4 — staged-file sweep lives in `ToyWorkspace::open`, policy = delete all**
  (`StagedWrite::abandon()` on every `scan_staged` hit). Safe: staged bytes are
  never the sole copy of anything — `WriteFile.contents` lives durably in the
  intent record; third-party bytes only ever live in the target, which the sweep
  never touches. Trivially idempotent.
- **D02.5 — `Graph` steps short-circuit in the step loop**: verify is treated as
  `Prestate` and "apply" is a synthesized no-op ack
  (`observed_poststate = expected_poststate`) because graph ops land atomically at
  Finalize. No Graph steps exist in the M2 scenario; the branch exists for M4.
- **D02.6 — binary location: conformance gains `[[bin]] lim-toy`** (AM-2.4), a
  ~20-line argv shim (`lim-toy exec <root> <scenario>` / `lim-toy recover <root>`,
  no clap) delegating to `liminal_daemon::runner::{exec, recover}`.
  `CARGO_BIN_EXE_*` is only injected for targets owned by the compiling crate;
  path-guessing `target/debug/liminald` breaks under `CARGO_TARGET_DIR`; per-case
  `cargo run` is slow and non-hermetic. Consequence: ALL exec/recover semantics
  live in the daemon library — `liminald`'s `main.rs` and `lim_toy.rs` are both
  transport shims and cannot drift.
- **D02.7 — one injector per concern**: `runner::exec` builds one
  `EnvCrashInjector::from_env()` and moves it into the scenario driver;
  `ToyWorkspace::open` builds its own for the recovery driver. Safety invariant
  (documented at both construction sites): `exec` requires a fresh root, so
  open-time recovery finds zero nonterminal intents and fires zero boundaries —
  occurrence counting never spans the two instances.
- **D02.8 — aux key/value asymmetry is deliberate**: the aux key uses the prefixed
  Display form (`repair:<uuid>`, self-describing in NDJSON) while ids INSIDE the
  JSON are bare UUIDs (`#[serde(transparent)]`). Do not "fix" this.

## Data schemas

Namespace constant: `liminal_graph::store::ns::ILRP_INTENT = "ilrp.intent"`
(AM-2.3 creates the `ns` module; `liminal_jurisdiction::ilrp` re-exports it as
`AUX_NS_INTENT` for local readability). Key = `RepairId` Display
(`repair:<uuid>`), produced by `plan.id.to_string()`, parsed by
`key.parse::<RepairId>()`. Value = `serde_json::to_value(&RepairIntent)` — the
derived serde shapes ARE the schema; no hand-rolled DTO. Every aux update rewrites
the whole value.

## Algorithms

### A. `IlrpDriver::prepare`

1. `topo_order(&plan)?` — validates DAG/unknown-step up front; discard the order.
2. `key = plan.id.to_string()`; if `store.get_aux(ILRP_INTENT, &key)?` is `Some`,
   return `Err(IlrpError::Store(StoreError::Conflict(format!("intent exists: {key}"))))`.
3. `intent = RepairIntent { plan, state: Prepared, evidence, acks: BTreeMap::new() }`.
4. One transaction: `put_aux(ILRP_INTENT, &key, to_value(&intent))`; commit with
   `meta("ilrp:prepare", Origin::Human)` where
   `meta(p, o) = TxnMeta { actor: None, origin: o, at: Timestamp::now(), provenance: Some(p.into()), inverse: None }`.
5. `self.crash.crash_if_armed(CrashPoint::BeforeIntentCommit);`
6. Commit.
7. `self.crash.crash_if_armed(CrashPoint::AfterIntentCommit);`
8. Return `Ok(repair_id)` (captured before the move).

### B. `IlrpDriver::run` + internal `advance` (D02.1)

`run(repair)`: load intent (`None` → `NotFound`; malformed → `Corrupt` — never
guess); terminal → `Ok(state)` (idempotent re-run); else
`advance(repair, intent, Origin::Human)`.

`advance(id, mut intent, origin)` — `commit_intent(note)` = assert
`may_transition_to` where state changes (violation → `IllegalTransition`), then one
txn putting the whole intent with provenance `"ilrp:<note>"`:

1. `order = topo_order(&intent.plan)?`.
2. **Prepared:** `state = Applying`; `commit_intent("state:applying")`. *(No fault
   point — the R4 §10 transition boundary is separately covered by
   `state=applying` record is separately reachable by recovery.)*
3. **Applying:** for each `step_id` in `order`:
   a. Acked already → skip. *(Completed durable evidence is never re-audited by the
   in-flight saga; a post-ack foreign edit is a NEW foreign-edit event for the
   M3+/M5 checker/overlay machinery, not a rewind of this step — v4 §7.8 step 3.)*
   b. If `operation` is `Graph(_)` → D02.5 short-circuit.
   c. Else `match self.executor.verify(m)?`:
      - **Prestate** → `ack = self.executor.apply(m)`: `Err(Contested{..})` → go
        to 6; other `Err` propagates. Surround the effect with
        `crash_if_armed(BeforeExternalApply)` and
        `crash_if_armed(AfterExternalApply)`. Then insert ack; surround
        `commit_intent("ack:<step-uuid>")` with `crash_if_armed(BeforeAcknowledge)`
        and `crash_if_armed(AfterAcknowledge)`.
      - **Poststate** → synthesize
        `ack = StepAck { step, observed_poststate: m.expected_poststate.clone(), at: now }`;
        insert; surround `commit_intent("ack:<step-uuid>")` with
        `crash_if_armed(BeforeAcknowledge)` and
        `crash_if_armed(AfterAcknowledge)`. *(No external-apply boundary — nothing
        external happened in this process.)*
      - **Neither** → go to 6.
   After the loop: `state = ExternalApplied`;
   `commit_intent("state:external-applied")`.
4. **ExternalApplied:** `state = Finalizing`; `commit_intent("state:finalizing")`.
5. **Finalizing:** `crash_if_armed(BeforeFinalize)` *(top of this branch, so both
   fresh runs and recovery re-entries cross the boundary "immediately before the
   Finalize transaction")*. Build ONE txn: for each step in `order` whose operation
   is `Graph(op)` → `txn.apply(op.clone())`; set `state = Committed`
   (legality-checked); put the whole intent (D02.2: kept, never deleted); commit
   `meta("ilrp:finalize", origin)`. On `Err(Conflict | NotFound)` (graph ops
   invalid against current state) → go to 6 (`Finalizing → NeedsReview` is legal);
   other store errors propagate. Then
   `crash_if_armed(AfterFinalizeBeforeNotify)`; return `Ok(Committed)`.
6. **needs_review:** `state = NeedsReview`; `commit_intent("state:needs-review")`;
   return `Ok(NeedsReview)`. Target files are never touched on this path —
   preservation IS the action. (Contested-overlay reification is M5.)

Happy-path enumeration for a k-step plan (C = commit, F = fault point fired after):

| # | Event | F |
|---|---|---|
| C1 | prepare: intent `prepared` | `ilrp/before_intent_commit:1`, `ilrp/after_intent_commit:1` |
| C2 | intent `applying` | — |
| — | external apply, step i (stage → rename) | `ilrp/before_external_apply:i`, `ilrp/after_external_apply:i` |
| C2+i | ack for step i persisted | `ilrp/before_ack:i`, `ilrp/after_ack:i` |
| C3+k | intent `external-applied` | — |
| C4+k | intent `finalizing` | — (then `ilrp/before_finalize:1` immediately before C5+k) |
| C5+k | FINALIZE: all Graph ops + intent `committed`, ONE record | `ilrp/after_finalize_before_notify:1` |

Baseline trace for `promote_single_step` (k=1) is therefore exactly:
`before_intent_commit:1, after_intent_commit:1, before_external_apply:1,
after_external_apply:1, before_ack:1, after_ack:1, before_finalize:1,
after_finalize_before_notify:1` — all eight registered points, so this one scenario
already satisfies the meta-test.

### C. `FsExecutor` (crates/liminal-daemon/src/executor.rs)

`pub struct FsExecutor { root: Utf8PathBuf }`; `abs(path) = root.join(&path.0)`;
predicates/acks carry the workspace-relative `PathId` exactly as written in the
plan.

`verify(m)`: extract the file path from the operation (`WriteFile{path,..}` at M2;
`InsertSourceId`/`External` → `Err(Executor("deferred to M4: <variant>"))`).
`obs = observe(&abs)?`, classify with `matches(pred, obs)`:

| `StatePredicate` | `obs = Some(o)` | `obs = None` |
|---|---|---|
| `FileContent { hash, .. }` | `o.hash == hash` | false |
| `FileAbsent { .. }` | false | true |
| `Any` | true | true |
| `NodeAt` / `RelationAt` / `ExternalRevision` | `Err(Executor("non-file predicate in file step"))` | same |

Return: prestate match → `Prestate` (**checked FIRST** — if pre and post both
match, e.g. identical contents, re-apply wins and is idempotent); else poststate
match → `Poststate`; else `Neither`.

`apply(m)` for `WriteFile { path, contents }`:

1. `staged = stage(&abs, contents)?`.
2. `expected_pre` = `FileContent{hash,..}` → `Some(hash)`; `FileAbsent` → `None`;
   `Any` → `observe(&abs)?.map(|o| o.hash)` (TOCTOU window accepted in the toy;
   documented); others → `Err(Executor(..))`.
3. `staged.commit_if(expected_pre)`:
   - `Ok(obs)` → `Ok(StepAck { step: m.id, observed_poststate: FileContent { path: path.clone(), hash: obs.hash }, at: now })`.
   - `Err(PrestateMismatch{..})` → best-effort remove the staged sibling, then
     `Err(IlrpError::Contested { step: m.id })`.
   - `Err(Io(e))` → `Err(Executor(e.to_string()))`.

### D. `recover_all` (v4 §7.8 step 5) — with per-branch idempotence argument

1. `all = store.scan_aux(ILRP_INTENT)?` (key-ordered — deterministic).
2. Deserialize each; malformed → `Err(Corrupt)`.
3. Filter `!state.is_terminal()`.
4. For each, in key order: `outcome = advance(id, intent, Origin::Recovery)?`.
5. Return `Vec<(RepairId, IntentState)>` (empty when nothing was nonterminal).

Resume semantics per observed state:

- **Prepared** — no external effect exists; run the full pipeline. Idempotent:
  crashing again reproduces a state this table covers.
- **Applying** — per-step verify walk. Acked steps skip. Un-acked: `Prestate` →
  re-apply (same staged bytes, same `expected_pre`; `rename(2)` atomicity means
  the target is entirely-old or entirely-new, never torn); `Poststate` → the apply
  landed but the ack-commit was lost — synthesize the ack, exactly the missing
  durable record; `Neither` → `NeedsReview`, target untouched. Never guess.
- **ExternalApplied** — all effects landed and acked; proceed to Finalizing, then
  finalize.
- **Finalizing** — the finalize txn writes `state=committed` **atomically with the
  graph ops in one log record**; observing `Finalizing` at recovery PROVES that
  record never committed → redo finalize. Exactly-once graph acceptance holds by
  record atomicity.
- **Terminal** — filtered; recovery performs zero commits. Hence a second
  `recover_all` finds nothing nonterminal and the world digest is unchanged — the
  idempotence assertion.

### E. World digest (crates/liminal-daemon/src/digest.rs)

```rust
pub fn workspace_file_hashes(root: &Utf8Path) -> io::Result<BTreeMap<String, String>>;
pub fn world_digest(root: &Utf8Path, store: &GraphStore) -> Result<String, WorkspaceError>;
```

Exclusions (forced by `ToyRun::trace_path()` living inside the root): the
`root/state` subtree and the exact root-level names `crash-trace.log`,
`recover-trace.log`, `scenario.toml`. **Nothing else** — `.lim-staged` files are
deliberately INCLUDED so a leftover staged file breaks digest idempotence loudly.

Byte-exact algorithm:

1. `h = blake3::Hasher::new(); h.update(b"liminal-world-digest/v1\n")`.
2. `h.update(format!("head:{}\n", store.head()?.0))`.
3. Every regular non-excluded file under root, sorted by workspace-relative UTF-8
   path (byte order): `h.update(format!("file:{rel}:{hex}\n"))`,
   `hex = ContentHash::of(&bytes).to_hex()`.
4. `(key, value)` in `store.scan_aux(ns::ILRP_INTENT)?` (key-ordered):
   `h.update(format!("intent:{key}:{json}\n"))`, `json = serde_json::to_string`
   (canonical: workspace serde_json has no `preserve_order`, so maps are
   key-sorted). Hashing full JSONs of ALL intents — including terminal — catches
   recovery mutating acks.
5. `(key, _)` in `store.scan_aux(ns::JUR_OVERLAY)?`:
   `h.update(format!("overlay:{key}\n"))` (empty until M5; future-proofs the digest).
6. Output: 64 lowercase hex chars of `h.finalize()`.

### F. `liminald exec` / `recover` (crates/liminal-daemon/src/runner.rs)

```rust
pub fn exec(root: &Utf8Path, scenario_path: &Utf8Path) -> anyhow::Result<()>;
#[derive(Serialize)]
pub struct RecoverOutcome { pub terminals: Vec<IntentState>, pub world_digest: String }
pub fn recover(root: &Utf8Path) -> anyhow::Result<RecoverOutcome>;
```

`main.rs` delegates; `Exec` prints NOTHING on success (silence culture; failures
via anyhow to stderr, exit 1); `Recover` prints one JSON line of `RecoverOutcome`.

`exec` algorithm: (1) `ScenarioScript::load` (model relocated per AM-2.1);
(2) setup files: `create_dir_all` + `fs::write` — pre-existing world state, written
directly, not system-mediated; (3) `ToyWorkspace::open(root)?` (sweep + recovery;
no-op on fresh root, D02.7); (4) setup buffers (AM-2.2): contents = file bytes;
one minted `ClientId` per distinct client name; any `setup.graph` entry →
`bail!("setup.graph is M4")` *(M3 order supersedes this with real ingestion)*;
(5) steps in order — `buffer_edit { client, path, find, replace }`: replace FIRST
occurrence in the buffer, absent `find` → bail (scenario bug, loud);
`save { client, path }`: build the plan below, `driver.prepare` + `driver.run`;
any other kind → `bail!("step kind {kind:?} not implemented until M3/M4")`;
(6) if `expect.terminal` is `Some(t)`: compare
`normalize(t) == normalize(<kebab name of terminal>)` where
`normalize = lowercase + strip '-'` (fixtures write `"Committed"`, serde writes
`"committed"`); (7) exit silently.

`save` → plan construction, exact:

1. `rel = PathId(path)`; `base = observe(&abs)?`.
2. `expected_prestate` = base present → `FileContent{path: rel, hash: base.hash}`,
   else `FileAbsent{path: rel}`.
3. `expected_poststate = FileContent{path: rel, hash: ContentHash::of(&new_bytes)}`.
4. One `ProposedMutation` — `subject: Node(NodeId::new())` *(M2 placeholder; M3
   replaces with the parsed block Node)*, `operation: WriteFile{path, contents}`,
   fresh `RepairStepId`/`IdempotencyKey`.
5. `RepairPlan` — fresh `RepairId`; basis:
   `WorkspaceBasis { transaction: TransactionId::new() /* M6 makes capture real */,
   perspective: ClientScoped{client}, components: [(JurisdictionKey::Path(rel),
   FileContent{path, hash: base.hash})] when base exists else empty }`;
   `dependencies: []`; `inverse: None`.
6. `evidence = StructurallyDisjoint { description: "single-step file promotion;
   durable file unchanged since buffer base (verified as ILRP prestate)" }` — the
   M4 safety machinery does not exist yet; this hardcoding is the M2 scope
   boundary, commented with R4 §6.
7. `driver = IlrpDriver { store: ws.store(), executor: FsExecutor::new(root),
   crash: <exec-scoped injector> }` — one driver reused for prepare and run.

`recover` algorithm: `ToyWorkspace::open` (sweep + `recover_all` inside, outcomes
stashed behind the additive `recovery_outcomes()` accessor); then rescan ALL
intents in key order and collect every state (so a crash after finalize still
reports `["committed"]` and a second recovery reports identical terminals); any
nonterminal after recovery → bail (recovery bug, loud); compute `world_digest`.

### G. `ToyRun` bodies (conformance/src/harness.rs) + `lim-toy`

- `baseline(scenario)`: `toml::to_string(scenario)` → `root/scenario.toml` (the
  frozen signature passes the parsed model; `ScenarioScript` derives Serialize —
  if toml serialization ordering errors surface, that is a Discovered gap, not a
  workaround site); spawn `env!("CARGO_BIN_EXE_lim-toy")` with
  `["exec", root, root/scenario.toml]`, `env_remove(LIMINAL_CRASHPOINT)`,
  `LIMINAL_CRASH_TRACE = trace_path()`; ensure success else bail with stderr;
  `HitTrace::parse`; ensure hits non-empty.
- `run_to_crash(scenario, point, occurrence)`: same spawn +
  `LIMINAL_CRASHPOINT=<point>:<occurrence>`; ensure `!success`,
  `code().is_none()`, `signal() == Some(6)`; parse trace; **ensure
  `trace.fired(point, occurrence)`** — a crash test whose point never fired is a
  false pass and must fail here; return `CrashState`.
- `recover()`: spawn `["recover", root]` with crash arming removed and
  `LIMINAL_CRASH_TRACE = root/recover-trace.log` (separate file keeps the crash
  trace pristine and out of the digest); parse the JSON line; **assert every
  terminal `is_terminal()`**; return `RecoveryReport`.
- `crash_matrix(scenario)`:
  1. Baseline in its own root; capture trace + `workspace_file_hashes` (minus the
     E-exclusions).
  2. `expected = normalize(scenario.expect.terminal.unwrap_or("committed"))`.
  3. For every `(point, occ)` in `trace.enumerate_faults()` (ensure non-empty):
     fresh `ToyRun` (label `<id>-<point '/'→'-'>-<occ>`); `run_to_crash`;
     `r1 = recover()` — terminals non-empty, every normalized state == expected;
     `r2 = recover()` — `r2.world_digest == r1.world_digest` AND
     `r2.terminals == r1.terminals` (recovery that only works once is not
     recovery); if expected == committed: file hashes == baseline's (crash+recover
     converges to the no-crash file world); no `.lim-staged` files remain.
- Additive `pub fn runnable_crash_scenarios() -> anyhow::Result<Vec<ScenarioScript>>`:
  loads from `fixtures/scenarios/` exactly the ids in
  `const RUNNABLE: &[&str] = &["promote_single_step"]; // M4 appends "dag_id_then_reattach"`
  — the single source of truth for matrix scope.

## Algorithms

1. Run one nextest expression selecting the seven D24.1 names across the `laws`
   and `classes` integration-test binaries. Require exactly seven passes and
   zero skips, retries, or failures.
2. In the authored no-trigger branch, assert the exact migration ignore remains.
   If a first persisted-format ADR is later accepted, its author amends this
   frozen branch with the exact ADR coordinate, adds the migration name to the
   aggregate selector, and supplies the active-test command; require its
   committed fixtures and pass in that expanded aggregate.
3. Run `just ci` once with retries disabled after the last fix. Preserve raw
   command status as the aggregate CI evidence.
4. Run `just gates`. With no persisted-format ADR, require 422 active, Phase 1
   backlog 0, Phase 1+ backlog 1, and total backlog 16. With the trigger active,
   require 423 active, both Phase 1 and Phase 1+ backlog 0, and total backlog 15.
5. Read the review packet's single status field and report it beside the gate
   evidence. Do not edit the packet or authorize Phase 2; the user owns the
   separate ratification decision.

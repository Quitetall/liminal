## Pre-made decisions

- **D19.1 —** annotations and source maps are ephemeral views over one exact
  `SourceBasis`; raw offsets are never persisted without its content hash and
  never claim cross-revision identity.
- **D19.2 —** `SyntaxForm` is exactly v4 §17's literal, node construction,
  relation construction, attribute assignment, ordered block, reference,
  expression, and macro invocation. Compact syntax is sugar that lowers to these
  forms; macro invocation is represented but not executed in M19.
- **D19.3 —** HIR preserves authorial spelling, source ranges, symbolic defaults,
  unresolved references, and provenance. Resolution materializes defaults and
  local references into a separate derived graph; it never mutates HIR.
- **D19.4 —** external-file source retains Jurisdiction. The L2 graph is marked
  derived, carries the exact Workspace Basis and source provenance, and is never
  selected as a governing Holder.
- **D19.5 —** stable debug JSON v1 is the only Phase 1 graph interchange. It is
  inspectable and deterministic but explicitly non-final and non-performance-
  critical; unknown or missing fields fail closed.
- **D19.6 —** canonical semantic IDs use UUIDv5 over
  `holder_source_id || syntax_form || canonical_semantic_path`; source offsets and
  content hash do not enter the ID. The resulting continuity is declared Anchored,
  never Explicit or Managed, unless source contains an accepted explicit ID.
- **D19.7 —** `Phase1Document::PartialEq` compares the normalized semantic
  Node/Relation projection and its Workspace Basis. It deliberately excludes
  diagnostics, source hashes, provenance coordinates, and source-map byte ranges,
  which may change when canonical spelling changes without semantic loss.

## Data schemas

In `liminal-hir`:

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum SyntaxForm {
    Literal, NodeConstruction, RelationConstruction, AttributeAssignment,
    OrderedBlock, Reference, Expression, MacroInvocation,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum AnnotationKind {
    Form, Token, Attribute, Reference, Error, Provenance,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Annotation {
    pub kind: AnnotationKind,
    pub range: SourceRange,
    pub hir: Option<HirId>,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct SourceMap {
    pub basis: SourceBasis,
    pub annotations: Vec<Annotation>,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash, Serialize, Deserialize)]
#[serde(transparent)]
pub struct HirId(pub u32);

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum HirValue {
    Null, Bool(bool), Integer(i64), String(String), Reference(HirId),
    List(Vec<HirValue>),
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct HirItem {
    pub id: HirId,
    pub form: SyntaxForm,
    pub range: SourceRange,
    pub name: Option<String>,
    pub value: Option<HirValue>,
    pub attributes: BTreeMap<String, HirValue>,
    pub children: Vec<HirId>,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct HirDocument {
    pub basis: SourceBasis,
    pub roots: Vec<HirId>,
    pub items: Vec<HirItem>,
    pub source_map: SourceMap,
}
```

`items` is dense and sorted by `HirId`; every `roots`, `children`, and `Reference`
target exists; annotations are sorted by `(range.start, range.end, kind, hir)` and
remain within the exact source length.

In `liminal-cir`:

```rust
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct SourceProvenance {
    pub source: SourceId,
    pub content_hash: ContentHash,
    pub range: SourceRange,
    pub identity_grade: IdentityGrade,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DerivedGraph {
    pub basis: WorkspaceBasis,
    pub nodes: Vec<Node>,
    pub relations: Vec<Relation>,
    pub provenance: BTreeMap<NodeId, SourceProvenance>,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct DebugProvenanceV1 {
    pub node: NodeId,
    pub source: SourceId,
    pub content_hash: ContentHash,
    pub range: SourceRange,
    pub identity_grade: IdentityGrade,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct DebugGraphV1 {
    pub schema_version: u32,
    pub basis: WorkspaceBasis,
    pub source: SourceBasis,
    pub nodes: Vec<Node>,
    pub relations: Vec<Relation>,
    pub provenance: Vec<DebugProvenanceV1>,
}
```

JSON bytes are UTF-8, one pretty-printed object, two-space indentation, LF only,
and one trailing LF. Struct field order above is canonical; every map is a
`BTreeMap`; `nodes`, `relations`, and `provenance` sort by ID; `schema_version`
must equal `1`; duplicate IDs, dangling endpoints, unknown fields, non-derived
nodes, and Basis/source-hash mismatch are errors.

In `liminal-format`, `Phase1Document` contains `hir: HirDocument`,
`graph: DerivedGraph`, and `diagnostics: Vec<Diagnostic>`. Its explicit
`PartialEq` implementation follows D19.7 by comparing the Workspace Basis and a
semantic projection of sorted Nodes/Relations; source hashes, ranges,
diagnostics, and provenance coordinates are excluded. `MarkdownFormatter` is
constructed with the selected Holder's stable `SourceId` and one immutable
`WorkspaceBasis`, then implements the existing `Formatter<Doc = Phase1Document>`
seam for both the constrained compact frontend and the §17 explicit debug form.

## Algorithms

1. Walk the M18 typed CST in source order and create annotations for each token,
   error region, attribute, reference, and recognized form. Allocate dense
   `HirId`s preorder from zero; validate the complete SourceMap before returning.
2. Lower compact Markdown sugar and explicit syntax into the same eight-form HIR.
   Explicit syntax accepts only `literal`, `node`, `relation`, `attribute`,
   `ordered`, `reference`, `expression`, and `macro`; unknown forms become HIR
   diagnostics while their M18 CST bytes remain lossless.
3. Resolve HIR at one caller-supplied `WorkspaceBasis`. Materialize symbolic
   defaults and local references; retain unresolved references as diagnostics;
   never perform I/O inside lowering. Derive IDs by D19.6, mark every Node
   `NodeFlags::DERIVED`, attach Anchored provenance, sort by ID, and reject dangling
   Relations.
4. Convert `DerivedGraph` to `DebugGraphV1`, validate every invariant, serialize
   with the fixed v1 framing, deserialize with `deny_unknown_fields`, and require
   structural equality. No JSON bytes are used as a governing store snapshot.
5. Canonical emission walks normalized HIR: attributes sort lexicographically,
   children retain declared order, literals use JSON string escaping, and every
   implicit default is written explicitly. Parsing compact or explicit input,
   emitting canonical explicit form, and parsing again must produce an equal
   `Phase1Document` under D19.7.
6. Fill the existing law test with compact/explicit pairs covering all eight forms,
   derived-graph provenance, malformed-but-retained regions, unknown JSON fields,
   and deterministic repetition. Invoke only
   `laws::check_canonical_round_trip`; do not duplicate or weaken its assertions.

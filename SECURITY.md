# Security Policy

Report suspected vulnerabilities privately to <briankhanglam@gmail.com> —
please do not open public issues for them. This is a pre-alpha Phase 0
research codebase with no supported releases, so there is no bug bounty and
no fix-SLA; reports are still appreciated and will be acknowledged. This
reporting policy complements the normative
[Phase 0 threat model](docs/security/threat-model.md) (v4 §108).

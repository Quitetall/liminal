sees instead.

name. "None change shape" is acceptable only with a justification. An
accepted RFC's listed fixtures MUST be updated in the change series that
implements it. State whether held-out corpora (v4 §7.4, R4 §2.2) are
affected; if scored corpora change, that forces a new corpus version.
